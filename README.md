## 特点

- **免费无需注册** — 打开网页即用，无广告水印
- **隐私优先** — 图片/文档处理全程在浏览器内完成，不上传服务器
- **大整数 JSON** — 无损解析超过 JavaScript 安全整数范围的超大数字
- **PDF 批量处理** — 合并、拆分、压缩、加解密、水印一站式解决
- **AI 智能提取** — PDF 文字提取支持 OCR，自动识别扫描件内容
- **移动端适配** — 响应式布局，手机平板均可流畅使用

## 技术栈

```
Flask + Gunicorn + Nginx
纯前端图片/PDF处理（Client-side）
HTML + CSS + Vanilla JS
```

## 快速部署

```bash
# 1. 克隆
git clone https://github.com/besql/besql.git && cd besql

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python app.py
```

生产环境请参考 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 项目结构

```
besql/
├── app.py              # Flask 应用入口，路由与 SEO 资源
├── tools/              # 各工具模块（每工具一个 blueprint）
├── templates/          # Jinja2 模板
├── static/             # 静态资源
├── scripts/            # 运维脚本（索引推送、日志分析）
├── tests/              # 测试套件
├── DEPLOYMENT.md       # 阿里云部署指南
└── requirements.txt    # Python 依赖
```
